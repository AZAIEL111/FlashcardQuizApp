# CodeAlpha_FlashcardQuizApp

🧠 Overall
The app stores flashcards as a list of question–answer pairs and displays them one by one in a window. Users can:

View questions
Reveal answers
Move forward/backward
Add new flashcards
Delete existing ones

💡 Simple Summary

👉 This app is a basic interactive flashcard system that helps users learn by showing questions and answers with navigation and editing features.
